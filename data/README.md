# Local data layout

Logical directories are bronze (originals), silver (qualified observations), gold (analysis outputs), and reference-cache (pinned public annotations). Create them only when needed; their contents are ignored by Git.

No patient files belong in this repository. Keep small factual source/rights registers in research/registries and actual check receipts in research/qualification. See [medallion layout](../research/medallion-layout.md) and [initial intake receipt](../research/qualification/initial-source-receipt.md). No Silver or Gold scientific data have been produced.

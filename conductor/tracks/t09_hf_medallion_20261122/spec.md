# T09 — Source-bound storage and publication

## Scope

Publish the reviewed API catalogue and three already qualified Kabuki source archives to one public `edithatogo/rare-omics-atlas` Hugging Face dataset, with explicit Bronze/Silver/Gold paths. GitHub owns code, manifests and receipts, not array bytes. Use the official Hugging Face Hub client for commits/uploads, with a small operational Python boundary; do not reimplement upload protocols in Rust.

## Acceptance

- A reviewed allowlist binds every local/source object to exact path, bytes, SHA-256 and redistribution basis. Preserve source attribution, including supplied vendor annotation files; no claim that source data become public domain.
- Raw GEO archives remain byte-identical. Allowlisted metadata can be normalized Silver metadata, but no biological Silver matrix or Gold result is fabricated.
- Dry-run checks and failure cases reject mismatched hashes, paths and unsupported release entries. Auth values never enter logs or Git.
- Actual Hub publication is tied to a reviewed GitHub source commit; observed Hub revision and path/hash/size results are recorded. Update the existing estate registry with a schema-valid new canonical entry, preserving unrelated rows.
- Official self-hosted local verification/publication workflows are configured for trusted main/manual use. No automatic public-PR execution or claim that the owner's runner has been registered. This track accepts observed cloud publication; device qualification remains separate.
- Independent Ponytail review and post-publication read-back precede archival.

Source distribution follows GEO's affirmative public-data policy and exact source notices. The owner authorises this bounded mirror and integration. Do not add a new blanket author-consent or HREC prerequisite solely for copying already public source objects. Institutional admission to the later research analysis remains distinct.

## Agent batches

One manifest/publisher batch, one review/fix batch, one source-bound upload/read-back batch, then archive. Record actual durations, queue/error outcomes and any external credential/device limit.
